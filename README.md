# Sales & Customer Analytics

A personal data analytics project focused on understanding sales performance, customer behaviour, and business trends using a retail transaction dataset in Microsoft Excel.

## Project Overview
This project uses the provided sales dataset to explore patterns across time, geography, products, and customer segments. The goal is to turn raw transactional data into business insight and present findings clearly through analysis, KPI summaries, and a dashboard.

## Project Aim
To analyse retail sales and customer data to identify trends, segment behaviour, and performance drivers that support evidence-based decisions.

## Tools Used
- Microsoft Excel
- Git
- GitHub
- Data profiling and cleaning techniques in Excel

## Repository Structure
- `Data/Raw/` - original raw dataset
- `Data/Cleaned/` - cleaned and validated data outputs
- `docs/` - project proposal and supporting documentation
- `reports/` - analysis summaries and reporting outputs
- `Images/` - charts and visual assets
- `excel/` - workbook files or related Excel assets
